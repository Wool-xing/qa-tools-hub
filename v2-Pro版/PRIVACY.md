# 隐私政策 (Privacy Policy)

## 我们收集的数据

| 数据 | 用途 | 保留期限 |
|------|------|----------|
| 用户名 | 账号标识 | 账号存续期间 |
| 邮箱 | 密码重置 | 账号存续期间 |
| 密码 (bcrypt哈希) | 身份验证 | 账号存续期间 |
| IP 地址 | 限流（临时） | 60 秒（限流窗口） |
| 学习进度 | 平台功能 | 账号存续期间 |
| 测试用例内容 | 用户生成内容 | 账号存续期间 |

## 我们不收集的数据

- 真实姓名、地址、电话号码
- 支付信息
- 浏览器指纹、设备标识符
- 第三方追踪 Cookie

## 你的权利

- **访问**: GET `/api/auth/me` 查看账户信息
- **导出**: GET `/api/auth/me/export` 导出所有个人数据 (JSON)
- **更正**: PATCH `/api/auth/me` 修改密码
- **删除**: DELETE `/api/auth/me` 永久删除账户及所有关联数据
- **密码重置**: POST `/api/auth/forgot-password`

## 数据安全

- 密码使用 bcrypt 哈希存储，永不明文保存
- JWT token 存储于浏览器 localStorage
- 传输层安全由反向代理 (Nginx) 的 HTTPS 保障
- 重置 token 使用 SHA-256 哈希存储，30 分钟后自动过期

## Cookie 与本地存储

本应用不使用 Cookie。以下数据存储在浏览器 localStorage：
- 登录 token (JWT)
- 深色模式偏好
- 实验室访问记录（仅本地）

## 第三方服务

本应用不自带第三方追踪。部署者可接入的第三方：
- SMTP 邮件服务（用于密码重置邮件）
- 反向代理 (Nginx) 访问日志

## 儿童隐私

本平台为测试工程师职业教育平台，不面向 13 岁以下儿童。
