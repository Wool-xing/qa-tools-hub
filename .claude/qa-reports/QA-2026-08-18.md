### CRITICAL

### HIGH
2. **SQL 沙箱 OOM DoS** `backend/app/routers/labs.py:59-75` — 只限行数不限单行大小，`randomblob(1GB)` 打爆 512M 容器。
   证据源：安全 agent 代码路径分析（未实测，逻辑必然，数值待压测）
3. **SECRET_KEY 空值可伪造 JWT** `backend/app/config.py:24-26` — 环境变量存在但为空时 `""` 不在弱密钥集合，无告警，HS256 空密钥签名。
   证据源：安全 agent 代码分析 + docker-compose 引用核对
4. **限流可绕过（XFF 首值信任）** `backend/app/routers/auth.py:51-55` — 客户端伪造 X-Forwarded-For 即绕过全部速率限制，登录无锁定 → 无限爆破。
   证据源：安全 agent 代码分析；nginx `$proxy_add_x_forwarded_for` 行为核对
5. **delete_account 孤儿数据** `backend/app/routers/auth.py:261-272` — SQLite 无 `PRAGMA foreign_keys=ON`，ondelete 不生效，删号留孤儿数据。
   证据源：质量 agent 代码分析
6. **事件循环阻塞** `backend/app/routers/levels.py:193` + `auth.py:352` + `labs.py:300-311` + `auth.py:204-214` — 同步 subprocess/smtplib/bcrypt/CPU 循环共 4 处阻塞 async 事件循环。
   证据源：质量 agent 代码分析（submit 用 to_thread 而 run 不用 = 明显遗漏性不一致）
7. **前端本地部署白屏** `backend/app/main.py:228-235` + `frontend/vite.config.js base` — SPA fallback 对 /assets/ 404 也回 index.html（200 text/html）→ MIME 错误白屏；build base `/QA_Test/` 与本地根路径服务不匹配。
   证据源：Playwright 实测 console 错误 6 条（MIME type text/html）
